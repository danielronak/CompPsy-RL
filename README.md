# Computational Analogues of Post-Decision and Self-Evaluative Biases in RL Agents

This repository contains the source code, experimental harness, and LaTeX manuscript for the paper **"Computational Analogues of Post-Decision and Self-Evaluative Biases in Reinforcement Learning Agents."** 

It provides a full, reproducible computational framework demonstrating how hallmark human psychological biases (Cognitive Dissonance, Impostor Syndrome, Self-Handicapping, and Choice Overload) can emerge in standard RL agents (Tabular Q-Learning and Deep Q-Networks).

## Repository Structure

- `src/` - Core Python module containing the environments, agents, and analysis code.
  - `agents/` - Implementations of `TabularQAgent`, `DQNAgent`, and the `ConfidenceModule`.
  - `environments/` - Implementations of the multi-armed `Bandit` and `Gridworld` environments.
  - `experiments/` - Individual scripts for running Experiments 4.1 through 4.4, plus DQN replications.
  - `analysis/` - Code for statistical testing, plot generation, and cross-experiment mechanistic analysis.
- `latex/` - LaTeX source code (`paper.tex`), bibtex references, and generated figures.
- `results/` - All raw JSON outputs and plots generated by the experiments.
- `run_all.py` - Master script to reproduce all experiments sequentially.
- `compile_paper.py` - Script to automatically compile the markdown draft into HTML and PDF using LaTeX.
- `requirements.txt` - Python dependencies required to run the code.

## Reproducing the Experiments

The experiments are fully deterministic given the random seeds (20 seeds per condition). You can reproduce all raw results, statistical tests, and figures with a single command.

### 1. Setup the Environment

We recommend using a virtual environment (Python 3.8+):

```bash
# Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows, use `.venv\Scripts\activate`

# Install required dependencies
pip install -r requirements.txt
```

*(Note: PyTorch is used for the DQN replications. The CPU version is sufficient as the networks are small).*

### 2. Run the Full Pipeline

To execute all experiments (4.1 through 4.4, plus the DQN replications and human benchmark plotting), run:

```bash
python run_all.py
```

This will:
1. Run `exp_dissonance.py` (Exp 4.1: Cognitive Dissonance)
2. Run `exp_impostor_handicap.py` (Exp 4.2 & 4.3: Impostor Syndrome & Self-Handicapping)
3. Run `exp_choice_overload.py` (Exp 4.4: Choice Overload)
4. Run `exp_dqn_replication.py` (DQN Architecture Generalization)
5. Run the shared mechanistic analysis and human benchmarking plots.

All outputs will be saved to the `results/` directory, and plots will be automatically copied to `latex/figures/` for the paper compilation.

### 3. Compiling the Paper

If you wish to compile the final PDF or HTML from the source files:

```bash
python compile_paper.py
```
This script requires `pdflatex` to be installed on your system. It will output `paper.pdf` and `paper.html` in the root directory.
